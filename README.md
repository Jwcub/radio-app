Denna webbaplikation använder sig av Sveriges Radios öppna API för att visa kanaler, tablåer och spela upp ljud från Sveriges Radio. 

**Funktioner i applikationen:**
- Hämta kanaler från Sveriges Radio och visa i en lista på webbplatsen.
- Visa information om kanalen när man rör muspekaren över kanalnamnet.
- Vid klick på kanalnamnet visas tablå för kanalen på webbplatsen. 
- Applikationen sorterar bort program som redan passerat från tablån.
- Via en rullista går det att välja hur många kanaler som ska läsas in.
- Antalet valda hämtade kanaler visas med samma antal i rullista för att kunna lyssna på radiokanal.
- Antalet valda kanaler lagras i LocalStorage och visar samma antal även när sidan laddas om.
- Senast besökta kanaltablå sparas i LocalStorge och visas som förval vid omladdning av sidan.
- Senast besökta kanaltablå visas även som förval på radioväljaren. 
- Information om vald radiokanal visas ovanför kanaltablå.
